Harika! Aşağıda Boğaziçi Barter uygulaması için Codex CLI uyumlu, agents-tabanlı geliştirme sistemini (örneğin: auth-agent, payment-agent, listing-agent gibi görev odaklı otomasyon birimlerini) tam olarak destekleyen, eksiksiz bir PRD + Subtask Planı sunuyorum.

Bu doküman:

Clean Architecture + Agent-Based Development modelini birleştirir,
Her agent’ın kendi CLI komutlarını, kod üretme şablonlarını, test senaryolarını ve sorumluluk alanlarını tanımlar,
Tüm Türkiye yerel ödeme sistemlerini ve barter iş akışlarını kapsar,
Geliştirme ekibinin tam otomasyonla üretim yapabilmesini sağlar.
🧠 Boğaziçi Barter – Agent-Based Flutter PRD (Codex CLI Optimized)
🎯 Hedef: Her işlevsel birim (auth, payment, listing, barter, admin) için bağımsız bir Agent tanımlanacak. Her agent kendi CLI komutlarıyla modül oluşturacak, test edecek ve entegre edecek.

codex init project --name=bogazici-barter --agents=auth,listing,barter,payment,chat,admin,i18n,monitor

# Her agent'ı ayrı ayrı çalıştır
codex agent auth --with=kyc,otp,biometric
codex agent listing --steps=6 --with=barter-pool,media,delivery
codex agent payment --providers=papara,iyzico,tosla,paytr,bkm_express,paycell,param --webhooks --fees
codex agent barter --with=escrow,tracking,rating,dispute
codex agent chat --provider=stream --encryption --attachments
codex agent admin --moderation=levels --analytics
codex agent i18n --langs=tr,en,ar --rtl --auto-extract
codex agent monitor --firebase --perf --kpi

# Tüm agent'ları toplu çalıştır
codex run agents --all

# Test üretimi
codex test --agent=payment --coverage=90
codex test --agent=listing --type=widget,integration

# Build & Deploy
codex build --platform=android --flavor=prod --obfuscate
codex deploy --target=play-store --track=internal

✅ 5. Sonuç
Bu PRD:

Agent-based development ile modüler, sürdürülebilir ve paralel geliştirme sağlar,
Codex CLI ile her agent kendi yaşam döngüsünü yönetir (oluşturma → test → deploy),
Türkiye yerel ödeme sistemlerinin tamamını derinlemesine entegre eder,
Barter havuzu, emanet, KYC, çoklu dil, admin moderasyonu gibi tüm ihtiyaçları kapsar.
